# Blinkit Product & Delivery Analysis Dashboard (Excel)

![Dashboard](dashboard.png)

## Overview
Interactive Excel dashboard analysing 13,000 quick-commerce products across 10 cities.

## Key Insights
- Total revenue: 509M; Pune is the top city (53.8M)
- Household is the top category (~121M)
- 20% of deliveries are delayed
- Organic products contribute 24% of revenue

## Tools
Excel, Pivot Tables, Pivot Charts, Slicers, GETPIVOTDATA

## Data Cleaning
- Split single-column CSV into 25 columns
- Fixed date formats, renamed "None" to "No Offer"
- Added Revenue and Profit calculated columns
